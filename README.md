# QAi生活網｜智慧社區整合服務平台（PWA）

> **產品簡介**：QAi生活網是專為「公寓大廈 / 社區管委會 / 住戶」打造的**全端數位智慧社區整合平台**。以 **PWA（漸進式網路應用程式）** 架構開發，免安裝 App、手機加入主畫面即可使用，涵蓋「住戶服務、後台管理、數位管控、關懷救援」四大面向，協助社區全面**無紙化、數位化、節省管理人力、提升居住生活品質**。
>
> **技術堆疊**：`Firebase Auth / Firestore / Storage` + `原生 HTML / CSS / JavaScript` + `Service Worker（PWA 離線快取）` + `WebRTC 對講`
>
> **目前版本**：CACHE_VERSION `nwapp-v282`（每次升級需同步三項版本，詳見後方部署 SOP）

---

## 🏗️ 系統角色權限

| 角色代號 | 角色名稱 | 主要權限與使用場景 | 預設入口頁 |
|---|---|---|---|
| **Admin** | 系統管理員（平台端）| 跨社區總管理、建立/停用社區、指派社區後台管理員、模組啟用開關、全域系統設定 | `system.html`（系統社區設定）|
| **Staff** | 社區後台/管理員（管委會 / 總幹事 / 秘書）| 單一社區後台全功能：住戶造冊、包裹登記、訪客管理、公告發布、設施/停車/活動後台、歷史影片管理 | `admin.html`（社區 APP 後台）|
| **Resident** | 住戶 | 社區前台：看公告、領包裹、預約設施/停車、訪客邀請、看區大直播、SOS 呼叫、繳費（未來） | `member.html`（住戶前台）|
| **Visitor** | 訪客（不需登入）| 訪客自助登記（警衛廳平板或 QR Code 掃描），完成即自動通知住戶 | `visitor.html`（訪客登記）|

## 🚀 版本升級 & 部署 SOP（鐵則）
> ⚠️ **每次修改 JS / HTML / CSS 檔案後，以下 3 項必須完全同步升級，否則使用者手機會吃到 PWA 舊快取，導致改了卻看不到變化！**

### Step 1：升級 `sw.js` 三大項目
- ✅ ① **`CACHE_VERSION` 全域版號**（例 nwapp-v281 → nwapp-v282，+1 即可）
- ✅ ② **`PRECACHE` 陣列內所有修改過檔案的 `?v=` 版本參數**（例：`live-meeting.html?v=29` → `v=30`）
- ✅ ③ **所有 HTML 頁面中的 `<link>` 與 `<script>` 引用的 `?v=` 版本參數**（例：`live-meeting.html` 內 `<script src="js/live-meeting.js?v=23">` → `v=24`）

### Step 2：如果有修改 Firestore 權限規則
- ✅ ① 修改 **兩份規則檔** 兩份內容必須完全一致：
  - `c:\Users\...\nwapp\nw-app-v2\firebase.rules`（根目錄）
  - `c:\Users\...\nwapp\nw-app-v2\firebase\firebase.rules`（firebase 子目錄）
- ✅ ② 執行部署指令（PowerShell 5）：
  ```powershell
  firebase.cmd deploy --only firestore:rules
  ```

### Step 3：PWA 快取驗證（必做）
1. 打開 Chrome DevTools → Application → Storage
2. 點選 **「Clear site data」** 全部清除
3. 按 `Ctrl + Shift + R` 強制重新整理（跳過快取）
4. 確認畫面有你的修改 → 確認 `Application → Service Workers` 顯示最新版號
